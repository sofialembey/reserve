# RESERVE SMART NETWORK

Интерактивный конкурсный прототип платформы подбора складских мощностей.

## Запуск
Откройте `index.html` в современном браузере. Сборка и сервер не требуются: CSS, JavaScript и демонстрационные изображения встроены в файл.

## Разделы прототипа
- Подбор складов и фильтрация демонстрационных предложений
- Smart Economics — сценарное сравнение затрат
- What-if Simulator — изменение нагрузки и транспортных затрат
- Digital Twin — интерактивная модель складских зон и ячеек
- Кабинет владельца склада
- Демонстрация этапов сделки и SLA

## Важное ограничение
Прототип работает на синтетических данных. Складские предложения, тарифы, KPI и запасы не являются реальными коммерческими предложениями и не синхронизированы с WMS, ERP, датчиками или платёжными системами. Заявки не отправляются на сервер.

## Структура
`index.html` — автономная версия сайта, подготовленная для демонстрации и дальнейшего развития.
